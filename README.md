# 야구 기록 노트

타석·수비 기록과 경기 영상을 남기고 차트로 분석하는 1인용 웹앱입니다.
설치해서 쓸 수 있고(PWA), **인터넷 없이도 동작**합니다.
기록은 서버로 보내지 않고 **기기 안에만** 저장됩니다(localStorage · IndexedDB).

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체 (이 파일 하나에 화면·기능이 모두 들어 있습니다) |
| `manifest.json` | 앱 이름·아이콘·실행 방식 |
| `sw.js` | 오프라인 캐시(서비스워커) |
| `icon-192.png` / `icon-512.png` | 앱 아이콘 |
| `apple-touch-icon.png` | 아이폰 홈 화면 아이콘 |

## 깃허브 페이지로 올리기

1. 깃허브에서 새 저장소를 만들고, 위 파일 **6개를 최상단(루트)에** 올립니다. 폴더를 만들지 마세요.
2. 저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, 브랜치는 `main` / `/ (root)`로 지정하고 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소가 생깁니다.

## 휴대폰에 설치

- **안드로이드(크롬)**: 주소로 접속 → 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- **아이폰(사파리)**: 주소로 접속 → 공유 버튼 → `홈 화면에 추가`
  (아이폰은 사파리에서만 설치됩니다. 크롬으로는 안 됩니다.)

설치 후 **한 번은 인터넷에 연결된 상태로 실행**해야 앱 파일이 기기에 저장됩니다.
그다음부터는 비행기모드에서도 실행·기록·수정이 모두 됩니다.

## 앱을 고쳐서 다시 올릴 때

`sw.js` 첫 부분의 버전 숫자를 반드시 하나 올려 주세요.

```js
const VERSION = "v1";   →   const VERSION = "v2";
```

올리지 않으면 이미 설치한 기기가 예전 화면을 계속 씁니다.
새 버전은 앱을 두 번 정도 껐다 켜면 적용됩니다.

## 알아 두면 좋은 점

- **기록 백업**: 설정 화면에서 JSON으로 내보내기 / 불러오기를 할 수 있습니다. 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라지니 가끔 내보내 두세요.
- **영상**: 파일로 올린 영상은 기기 안에 저장되어 오프라인에서도 재생됩니다. 유튜브 등 링크로 등록한 영상은 인터넷이 있어야 재생됩니다.
- **유튜브 공개 범위**: `비공개` 영상은 유튜브 정책상 앱 안에서 재생되지 않습니다. `일부 공개(미등록)`로 올려 주세요 — 검색에는 노출되지 않습니다.
- **저장 공간**: 영상 파일은 용량을 많이 차지합니다. 하이라이트 클립 위주로 넣는 것을 권합니다.
